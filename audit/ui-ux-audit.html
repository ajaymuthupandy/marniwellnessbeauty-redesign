Marni Alas Retreat: UI & UX audit

22 October 2026 · Production build (next build + next start), Next.js 16.4.2 · Tested with agent-browser 0.38.2 (Vercel Labs) on headless Chrome

I opened all 12 page types at desktop (1440×900) and mobile (390×844) widths and took full-page screenshots. A script then measured contrast, image scaling and cropping, tap-target sizes, heading order, horizontal overflow and console errors on every page. Each finding below has its severity, the pages it affects, the cause and a suggested fix.

A · Contrast & accessibility

A1High

Gold text fails contrast everywhere

All pages: navigation, every heading, outline buttons, "Explore more" links, card titles, prices
Problem
#C9902E scores 2.8:1 on white and 2.5:1 on the grey #F2F2F2 bands. #CEA642 (active nav, hover) scores 2.29:1. WCAG AA needs 4.5:1 for normal text and 3:1 for large text, so even the 48px page titles fail. The 12px uppercase nav and button labels are the hardest to read.
Fix
Add a darker text gold, e.g. #8F6419 (5.2:1 on white, 4.7:1 on mist). Use it for h1–h4, .btn, .link-arrow and the nav labels in app/globals.css. Keep the current gold for fills, borders, icons and text on dark backgrounds, where it passes (5.7:1 on #222).
A2Medium

Grey meta text is too light

News dates, "Included in every package", "60 min" durations, footer bottom line
Problem
#7A7A7A on mist is 3.83:1. The 11px footer strip "UBUD · BALI | ERLENBACH · SWITZERLAND" on #222 is 3.71:1.
Fix
Use #6B6B6B (4.76:1 on mist) for --color-mute on light backgrounds. On the footer use white/60 or lighter, at 12px or more.
A3Medium

Tap targets are too small on mobile

Footer (all pages), "All packages", "All news", "Full beauty menu", contact email links
Problem
Footer "Explore" links are 17px tall, the footer email and phone links 19px, and arrow text links 20px, all with about 6px between rows. That is below the 24px WCAG 2.2 minimum and well under the 44px that fingers need.
Fix
Give links py-2 (or min-h-11 on mobile) and increase the footer gap-y. In components/Footer.tsx the Explore grid uses gap-y-1.5.
A4Low

11px text

"Book now" and "Ask on WhatsApp" small buttons, footer strip
Fix
Raise .btn-sm from 0.6875rem to 0.75rem or more. Text this small in uppercase with wide letter-spacing is hard to read.
A5Low

Gallery alt text and tab names are generic

/marni-gallery/
Problem
All 12 photos in a tab share the alt text "Spa & Retreat at Marni Alas Retreat". Screen readers hear the tab names as "SPA & RETREAT12" because the count is glued to the label.
Fix
Write one descriptive alt per photo in data/gallery.ts. Wrap the count in <span aria-label="12 photos"> or add a visually hidden separator.
A6Low

Two package cards have the same accessible name

Home, /package/, /wellness-in-bali/, package detail
Problem
The link names for the single and couple versions are both "Nature Lover Ayurvedic Experience, 4 Days / 3 Nights" (the same happens with "Luxury"). Include the occupancy in the label.

B · Images: unsuitable, low-resolution, badly cropped

B1High

Images that don't suit the design

Home, Bali, Microblading, Gallery, 404
Problems
  • Home, Kosmetikstudio panel: Kosmetik-Studio-Im-Hof-2.jpg is a screenshot of the Treatwell web page, including its "Termin buchen" button, star rating and carousel arrows. It looks broken and is unreadable on mobile.
  • Home, Special offer: Marni-Promotion.jpg is a social-media poster with the price and inclusions baked in. It repeats the card next to it, the small text is illegible on mobile, and screen readers can't read it.
  • Bali, "Beauty" tile: the crop shows a staff uniform with the logo "Mahottama Wellness Hospitality", which is a different brand name.
  • Microblading hero: a stock before/after collage of two eyes with a visible horizontal seam through the middle. It doesn't match the warm Balinese photography elsewhere.
  • Beauty cards: clean stock shots (cucumbers, nail polish) sit next to real in-house photos (pedicure), so the styles clash.
  • Gallery: a Legong dancer photo with a visible photographer watermark ("…RPHOTO", bottom-left) and a wedding photo, neither of which shows the retreat.
  • Home hero and 404: both use a dark leaf texture cropped from a PDF catalogue page (SPA-Beauty-Catalogue_page1_image1.jpg). It shows nothing of the villa or spa and leaves the right 60% of the hero empty.
Fix
Replace the Treatwell screenshot with a real studio photo. Use a clean villa photo for the offer and keep the details as text. Re-crop or replace the Beauty tile. Use a real retreat photo (villa, pool, flower bath) for the home hero. Remove watermarked images.
B2High

Low-resolution photos stretched to full width

Wellness, News, Villa, Home hero, villa carousels, package cards
Problem
86 of the 138 photos are 800px wide or less. The full-bleed heroes stretch them:
  • Wellness hero MARC0003_Yoga.jpg: an 800px source shown 1440px wide (1.8×, or 3.6× on a retina screen). It is visibly blurry and the subjects' heads are cut off.
  • News hero puri-manuaba-tour.jpeg and Villa hero precidential-room.jpg: 1200px sources in 1440×350 strips.
  • Villa room carousels: 800px sources shown about 800 CSS px wide, so they look soft on any 2× display.
Fix
Get the originals at 2000px or more for every hero, either from the photographer or the WordPress originals before resizing. Until then, don't run small photos full-bleed: use the split hero variant, or cap the hero width at the source width.
B3High

Landscape photos squeezed into tall tiles (heavy crop and blur)

Bali "Stay at", Gallery "See it for yourself", Package detail "More packages", Packages "How to book", Wellness "Make it a retreat"
Problem
The .section-end-grow rule (see C1) stretches these cards to the full screen height, giving boxes such as 329×535. A 3:2 photo in that box shows only about 40% of the image (2.4× crop). The sizes hint is based on box width (22vw ≈ 316px), so the browser downloads a 316px image and stretches it 2.4× to fill the height. The "How to book" photo is the worst case: pixelated, with the guest cut in half.
Fix
Give these tiles a fixed aspect ratio (aspect-[4/5] or aspect-[3/4]) instead of filling the height. If a tall tile is wanted, raise sizes to match the rendered height × aspect, e.g. (min-width:1024px) 40vw. Files: components/Closers.tsx, app/bali/page.tsx:148.
B4Medium

Mobile treatment thumbnails are thin slivers

/wellness-in-bali/ and /microblading-in-bali/ on mobile
Problem
On mobile each card's photo is a 104×228 strip cut from a 3:2 photo (3.3× crop). The result shows fragments of backs, hands and bowls instead of the treatment.
Fix
Use a square thumbnail aligned to the top (aspect-square self-start) or stack the photo above the text at 16:10 (components/TreatmentCard.tsx).
B5Medium

Portrait photos cut into wide strips on the Bali page

/bali/
Problem
Portrait spa photos fill 678×262 bento tiles (3.9× crop). The "Ayurveda massage" tile shows a torso holding a copper pot with the face cut off.
Fix
Choose landscape images for wide tiles, or set object-position per image.
B6Low

The same photos repeat

Packages, Wellness, Villa
Problem
The 7 package cards use 3–4 Bamboo Villa shots; the same exterior appears on cards 1, 3 and 6. The Ayurveda tab tile shows the same photo as the Udvartana card right below it. The Villa hero repeats the first slide of the carousel underneath.

C · Alignment & spacing

C1High

The last section is stretched to fill the screen, leaving empty bands

Villa, Contacts, Bali, Gallery, Wellness, Package detail (every page using .section-end)
Problem
.section-end in app/globals.css forces the final section to 100svh − header − footer. When the content is short, the extra space becomes empty bands. On Villa there is about 60px above and 200px below "Resort facilities". When the content is images, they stretch instead (B3). On phones the footer is also forced to fill a whole screen (max-md:min-h-[calc(100svh-…)]).
Fix
Remove the min-height fill and let sections size to their content with the normal .section padding. Drop the forced-height footer on mobile.
C2Medium

Cards with dead space at the top and content pushed down

Home (Welcome, Reviews), Microblading CTA, Packages "Plan a custom retreat", Wellness "Not sure which to choose?"
Problem
These cards stretch to the row height and push their content down or into the middle. The Microblading CTA has about 180px of empty space above its heading, the Welcome card about 110px above the logo, and the review quotes about 120px above the text. The boxes look half-empty.
Fix
Align content to the top (justify-start) with consistent padding, or shrink the card to its content and centre it vertically in the row.
C3Medium

Too many card styles, so there's no visual rhythm

Site-wide, most visible on Home
Problem
The site uses at least five card treatments: gold-outline box, grey fill, white with a hairline border, photo with dark overlay, and white tiles on grey. The first row of Home alone mixes a gold-outline card with two grey photo cards. The next row switches to a 7/5 split panel with a different height.
Fix
Pick two card types (photo-overlay for navigation, plain white or grey for content) and keep the gold outline for one primary CTA per page.
C4Medium

Review cards use different type sizes

Home
Problem
The first review is about 18px light and the next about 14px regular, which looks like a bug rather than a featured card. On mobile the next card peeks in at the smaller size.
Fix
Use one quote size. To feature a review, use a background or layout change, not a font change (components/ReviewCard.tsx).
C5Medium

News cards are mostly empty white space

/news/, news detail "More news"
Problem
In the horizontal cards the photo takes half the card and a small title floats in the middle of the other half, leaving about 60% blank. The First Aid photo crops off heads.
Fix
Use vertical cards (photo on top at 16:10, then title and excerpt), or add the excerpt to fill the text half.
C6Low

Villa page title row looks disconnected

/marni-villa-ubud/

The title and intro sit on the left. The "Book via WhatsApp" button sits top-right with the location line right-aligned below it, so the two columns don't share a baseline. The intro says "a secluded two-bedroom villa", but the page lists three different accommodations.
C7Low

Wellness category tiles crowd the treatment grid

/wellness-in-bali/

Make the tabs a slim text segmented control with a clear active fill, and leave 32–48px before the grid.
C8Low

Microblading, Wellness

C9Low

C10Low

Gallery, Packages

Vercel size optimisation

The deployable site is already small. Vercel uploads the source (about 15 MB, almost all of it public/images) and builds it remotely. The 365 MB .next folder on this machine is local build cache: it's gitignored and never uploaded.

What's already working

  • No JavaScript errors across all 24 page loads.
  • No horizontal overflow at 390px on any page.
  • Every image has an alt attribute; decorative ones are correctly empty.
  • Skip link, visible :focus-visible outlines, and a real dialog for the mobile menu that closes on Escape.
  • The gallery lightbox opens with a counter, arrows and a close button.
  • Maps are lazy-loaded, and the header height and image dimensions (from data/image-sizes.json) are reserved up front.
  • Old WordPress URLs redirect permanently; a sitemap and robots.txt are present.

Method: production build at localhost; agent-browser full-page screenshots at 1440×900 and 390×844 (device pixel ratio 1); an in-page script measured computed colour contrast, rendered vs. intrinsic image size, object-fit crop ratio, element bounding boxes, heading outline and metadata. Blur on retina screens will be roughly twice what is described here.
